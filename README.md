# 🎄 Christmas Gallery

Online shop for **Christmas Gallery**: Christmas balls, tree stars, fairy lights, Santa dolls, wreaths, stockings, gift boxes, candles and Christmas trees.

**Live site:** https://abid2929.github.io/Christmas-Gallery/
**Admin panel (demo on GitHub):** https://abid2929.github.io/Christmas-Gallery/admin/

## What is where
- `docs/` is the live site on GitHub Pages (Settings › Pages › Branch `main`, folder `/docs`).
  - The shop is Bangla first with an English button, works on phone and PC.
  - Orders are sent to WhatsApp with the full cart, name, phone and address.
  - Prices show "দাম জানতে মেসেজ করুন" until real prices are added.
  - `docs/admin/` is the same admin panel as the other shop sites, running in demo mode (sample orders, changes stay in that browser).
- The repository root is the full PHP version of the same shop (shared admin: PHP 8 + JSON files, no database). It can go to any cPanel `public_html` later; then orders, stock, reviews and the admin work for real.

## Admin panel (same on every shop)
Dashboard with quick actions, products (sizes, colours, gallery with colour photos, AI writer), categories, collections, inventory, orders with invoice and CSV, Steadfast courier hub, customers, reviews, hero banners, homepage CMS, reports, admins and roles, and settings (store, delivery, payment, courier, SMS, Meta Pixel + CAPI, Google SEO, password). Bangla by default, EN button for English.
