## Features

**Shop**
- Premium red and gold Christmas design with a soft entrance animation
- Product banner slider at the top, colourful category tiles right below it
- Bangla first, one tap to switch to English
- Separate shop page per category and a full product page (photo gallery, sizes, colours, related items), with working back button
- Christmas Trees first everywhere
- Cart and order with the full cart sent straight to WhatsApp
- Customer reviews and a ♡ wishlist
- Phone bottom tab bar: Home, Shop, Wishlist, Bag, WhatsApp
- Price not set yet? It shows "দাম জানতে মেসেজ করুন" (message us for the price)
- Fast and search friendly: Lighthouse mobile Performance 96, Accessibility 100, Best Practices 100, SEO 100

**Admin panel (in Bangla, same panel as the other Boostnix shops)**
- Dashboard with sales, orders and stock at a glance
- Products with sizes, colours, gallery and stock; categories and collections; inventory
- Orders with invoice and CSV export, Steadfast courier hub, customers, reviews
- Hero banners, homepage text (CMS), reports, admins and roles
- Settings: store, delivery charge, bKash/Nagad/COD, SMS, Meta Pixel + CAPI, Google SEO
- Show/hide eye button on passwords, forgotten-login reset

## Run it on your own hosting (cPanel)

1. Download this repository as a ZIP (green **Code** button › **Download ZIP**).
2. Upload everything except the `docs/` folder to `public_html` and extract it.
3. Open `yourdomain.com/admin` and create your own username and password on the first visit.
4. Add products, prices, photos and banners from the admin panel.

Forgot the admin login? Create an empty file named `reset-admin.txt` in the site folder, open `/admin` again and set a new username and password. Products and orders are kept.

A step-by-step Bangla guide is in [install-guide-bn.md](install-guide-bn.md).
