# 🎄 Christmas Gallery

Online shop for **Christmas Gallery**: Christmas ball sets, light-up tree top star, dancing Santa dolls, Santa hats and 3 sizes of Christmas trees.
WhatsApp / call: **01779-443155**

**Live demo:** https://abid2929.github.io/Christmas-Gallery/ (demo admin: https://abid2929.github.io/Christmas-Gallery/admin/)

## Features
- Bangla shop page, works on phone and PC, auto hero slider, snowfall, countdown to Christmas
- Cart, checkout (Cash on Delivery, Dhaka / outside Dhaka delivery charge), order number
- One-tap WhatsApp order for every product
- Admin panel (`/admin/`): orders with status, products (price, photo upload, stock, hide), settings, password change

## Tech
Plain PHP 8 + SQLite. No Node, no build step. Upload the files to `public_html` and open the site; the database creates itself.
See [install-guide-bn.md](install-guide-bn.md) for the step-by-step cPanel guide (Bangla).

`docs/` is a static demo for GitHub Pages (orders and price edits stay in your own browser, demo admin has no password).
